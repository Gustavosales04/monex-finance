# Gerenciador de Despesas

Este é o frontend de uma aplicação para controle e gerenciamento de despesas pessoais.

## 🚀 Funcionalidades

- **Autenticação:** Sistema de login com validação.
- **Persistência:** Armazenamento de token de acesso via LocalStorage.
- **Navegação:** Redirecionamento dinâmico após autenticação bem-sucedida.

## 📂 Estrutura de Pastas

```text
frontend/
└── js/
    └── login.js      # Lógica de autenticação e manipulação do DOM.
```

## 🛠️ Tecnologias Utilizadas

- HTML5 / CSS3
- JavaScript (ES6+)

## ⚙️ Como Executar

1. Certifique-se de que o backend da aplicação esteja em execução.
2. Abra o arquivo de login (`login.html`) em um navegador moderno.
